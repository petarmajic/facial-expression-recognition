# Dataset illustrations

I used the FER2013 training examples from Figure 3.2 of my bachelor’s thesis for both figures. The original image shows two faces per class. I used the top row for the class examples and arranged the crops in the classifier’s output order. [Source image](fer2013-training-examples.png) · [Thesis reference](../../docs/references.md#bachelors-thesis).

| Figure | How it uses the image |
| --- | --- |
| [Expression classes](../dataset-examples.svg) | Shows one example per class in the classifier’s output order (*angry*, *disgust*, *fear*, *happy*, *neutral*, *sad*, *surprise*). |
| [CNN architecture](../model-overview.svg) | Uses the *happy* face to illustrate the grayscale input to the first convolution. |
